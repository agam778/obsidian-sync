### Boolean Algebra
- A.B.C + A.B.C = A.B.C
- $\overline{A.B.C}$ + A.B.C = 1
- $\overline{A.B}$ + A.B = 1
- A + BC = (A+B) (A+C)
- A+ $\overline{A}$B = A + B
- AB+CD = (AB + C) (AB+D)

> [!Important] De Morgan's Theorem

- $\overline{XYZ}$ = $\overline{X}$ + $\overline{Y}$ + $\overline{Z}$ 
- $\overline{X+Y+Z}$ = $\overline{X}$ . $\overline{Y}$ . $\overline{Z}$

Q. Apply DeMorgan to the following:
- $\overline{X.Y.Z}$
- $\overline{X+Y+Z}$
- $\overline{\overline{X} + \overline{Y} + \overline{Z}}$
- $\overline{\overline{W} +\overline{X} + \overline{Y} + \overline{Z}}$

#### Examples:
a) A + AB  = A(1+B) = A
b) A(A+B) = A.A + AB = A + AB = A(1+B) = A
c) A + A'B = (A+A')(A+B) = 1(A + B) = A+B
d) A(A'+B) = A.A' + AB = 0 + AB = AB
